# Othello Game – Human vs Human & AI MinMax

This repository contains two implementations of the Othello (Reversi) board game developed in Python using Tkinter:

- **Human vs Human:** A two-player version where both players compete locally.
- **Human vs AI (MinMax):** A version featuring an AI opponent based on the MinMax algorithm with a configurable search depth and heuristic evaluation.

Both implementations include a graphical interface, legal move detection, disk flipping, score tracking, and end-game detection.

## Technologies
- Python
- Tkinter
- MinMax Algorithm
- Heuristic Evaluation

## Purpose
This project explores game development, artificial intelligence, and adversarial search algorithms through the implementation of Othello.
